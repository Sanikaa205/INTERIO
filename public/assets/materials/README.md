# Built-in floor-plan material assets

All textures here are **original INTERIO assets**. No third-party texture, scan
or remote URL is bundled, so there is nothing to attribute. They are released
under CC0 1.0 (public domain dedication) for use anywhere in this project.

## Sources and licence

| File(s) | Source | Licence |
| --- | --- | --- |
| `white-tile.svg`, `carrara-marble.svg`, `light-oak.svg` | Hand-written SVG tiles (first release) | Original, CC0 |
| every `*.jpg` | Generated by [`scripts/generate_materials.py`](../../../scripts/generate_materials.py) | Original, CC0 |

The JPGs are 512 x 512 px, built from periodic noise and integer-period
patterns so they tile without seams, and are deterministic (fixed seeds). Each
is well under 300 KB.

To regenerate: `python scripts/generate_materials.py` (needs `numpy` and
`Pillow`).

## Files

- Wood: `walnut`, `dark-walnut`, `grey-oak`, `maple`, `slat-panel`, `light-oak.svg`
- Tile: `grey-tile`, `beige-tile`, `black-tile`, `terracotta-tile`, `white-tile.svg`
- Marble: `calacatta-marble`, `nero-marquina`, `carrara-marble.svg`
- Granite and concrete: `black-granite`, `grey-granite`, `polished-concrete`
- Walls: `red-brick`, `whitewashed-brick`, `stacked-stone`, `wallpaper-stripe`,
  `wallpaper-geometric`, `wallpaper-damask`, `venetian-plaster`

## Adding or replacing textures

Reference a file from `materialCatalog.ts`. Variant IDs are stored in saved
projects, so never rename or remove an existing one. If you replace these with
third-party maps (e.g. ambientCG or Poly Haven, both CC0), record the source
URL and licence for each file in the table above.
