# Built-in floor-plan material assets

These SVG texture tiles are original project assets created for INTERIO's
material-preview catalog. They are intentionally small, repeatable base-colour
maps used by the first release only; no third-party texture or remote URL is
bundled here.

- `white-tile.svg` — matte white ceramic tile and grout
- `carrara-marble.svg` — pale marble with soft grey veining
- `light-oak.svg` — light oak planks

Replace these with licensed bitmap/PBR map sets only after recording the source
and license here. Keep the stable catalog variant IDs unchanged.
